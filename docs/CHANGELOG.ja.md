# 更新履歴

## [Unreleased]

## [2.2.0] - 2026-11-25

### 新規追加
- **更新履歴ページ**：サイドバーの「設定」の上に「更新履歴」を追加し、バージョンや種別ごとに見やすく整理して表示できるようにしました（検索・絞り込み対応）。
- **アプリ自動アップデート**：左上のメニューに「アップデートを確認...」を追加し、最新版の自動確認・ダウンロード・再起動案内に対応しました。
- **全体クイック検索**：`Ctrl+K` / `⌘K` でアイテム・クエスト・リーヴ・アチーブメント名を横断検索し、そのまま詳細や各ページへ移動できるようになりました。
- **ページ内検索と自動スクロール**：すべてのデータ画面とバージョン比較画面に `Ctrl+F` / `⌘F` 検索を追加し、検索結果や関連リンクから移動した際に左リストを自動で対象ページへ合わせて強調表示します。
- **多言語 UI・データ対応**：簡体字中国語・日本語・英語に対応し、初回起動時は OS の言語を自動選択します。右上のボタンからいつでも切り替え可能で、グローバル版設定時は対応言語でのデータ表示と副言語表示に対応します。

### 改善・調整
- **言語切り替えと狭小画面の最適化**：言語を切り替えても読み込み画面に戻らず現在の表示内容を維持するようにし、日本語・英語のフォントと `1024 × 640` 画面での表示を整えました。

## [2.1.0] - 2026-11-24

### 新規追加
- **クエスト・リーヴ閲覧機能**：クエストとリーヴの専用ページを追加し、報酬・前提条件・NPC 座標・ネタバレ防止付き会話テキスト・納品アイテム・報酬テーブルを確認できるようになりました。
- **収集品取引**：通常の収集品・お得意様取引・蒼天街納品の必要価値とスクリップ報酬をアイテム詳細に統合しました。
- **バージョン比較の拡張**：クエスト・リーヴ・収集品の変更履歴を比較対象に追加し、種別ごとの絞り込みと詳細画面への直接ジャンプに対応しました。

### 改善・調整
- **ゲーム内テキストと初期設定の改善**：ゲームテキスト内の特殊記号を整理して参照を展開し読みやすくしました。また、初回フォルダ選択と読み込み進捗表示をわかりやすく改善しました。
- **フォントと画面の調整**：視認性の高い英数字フォントを内蔵し、アイテム一覧の補足情報やアチーブメントのカテゴリ絞り込みを整理しました。

### 修正
- **アイコン縁の白浮き修正**：ライト/ダーク背景で一部ゲームアイコンの縁に白い輪郭が出る不具合を修正しました。
- **データ保存先の統一**：設定ファイルとスナップショットをユーザーデータ配下の `xiv-data-viewer` フォルダに統一して保存するようにしました。

## [2.0.0] - 2026-11-24

### 新規追加
- 最初のデスクトップ版をリリース。中国版/グローバル版クライアントの読み取り専用閲覧に対応し、アイテム・製作レシピ・採集カウントダウン・ショップ・リテイナーベンチャー・アチーブメント・バージョン比較・全量 CSV エクスポート機能を搭載しました。
